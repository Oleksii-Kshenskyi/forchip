# FORCHIP - an experiment implementing the CHIP-8 emulator in 4 programming languages

Full CHIP-8 implementation (capable of running compliant CHIP-8 ROMs) in 4 programming languages:

- C++
- Rust
- Odin
- Nim

# The Purpose

- Dive into the world of emulation and spend a few days implementing something that I will be able to have fun with and play around with the existing ROMs/games!
- Learn new languages for me: Odin and Nim. Get a feel for them and figure out if I like them.
- Brush up my systems programming skills and see if I can implement the emulator in a compliant way, see the ROMs actually run on software made with my own hands.
- When the work is done, compare all 3 languages and make either a section here in the README.md, or create a separate document comparing the 4 languages - how tough/annoying/frustrating/fun the implementation was in each of the 4, what I liked and disliked about each of them.
- Figure out which of these 4 languages I would like to use for my future personal projects based on how they performed in this project.

# Scope

- First pass in all 4 is plain CHIP-8 35-instruction set, that's it.
- In the future, once all 4 are ready and if the projects ends up being fun (or one of the tested languages ends up being fun), you can expand to Super-CHIP and/or XO-CHIP, some of the ROMs in the roms/ folder cover that.
